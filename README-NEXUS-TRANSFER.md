# Nexus — حزمة نقل المشروع

تحتوي هذه الحزمة على مصدر Nexus وملفات الإعداد وترحيلات قاعدة البيانات والتوثيق. استُبعدت قيم الأسرار وملفات البيئة و`node_modules` ومخرجات البناء والسجلات المحلية؛ ثبّت الاعتمادات مجددًا بعد النقل.

## التشغيل

يتطلب المشروع Node.js 22 وpnpm. بعد فك الضغط، أنشئ ملف بيئة محليًا بالقيم المناسبة لبيئتك ثم نفّذ:

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm dev
```

## متغيرات البيئة المطلوبة

لا تتضمن الحزمة أي قيمة سرية. ستحتاج إلى إعداد متغيرات الخادم وفق الخدمات التي ترغب في تشغيلها، ومنها:

### متغيرات إلزامية (يتوقف الخادم عند غيابها)

يتحقق الخادم من هذه القيم عند الإقلاع عبر `assertRequiredEnv()` في `server/_core/env.ts`، ويتوقف برسالة واضحة ورمز خروج غير صفري إذا كان أي منها مفقودًا أو أقصر من الحد الأدنى:

| المتغير | الحد الأدنى | الغرض |
|---|---|---|
| `JWT_SECRET` | 32 بايت | توقيع جلسات المستخدمين والتحقق منها |
| `DATABASE_URL` | — | سلسلة اتصال MySQL/TiDB |
| `ENCRYPTION_KEY` | 32 بايت | تشفير مفاتيح API الخاصة بالمنصات المخزّنة |
| `OAUTH_SERVER_URL` | — | نقطة تبادل رموز OAuth ومعلومات المستخدم |
| `VITE_APP_ID` | — | معرّف عميل OAuth ونطاق الجلسة |

> **تحذير:** تغيير `JWT_SECRET` يُبطل جميع الجلسات القائمة ويُخرج المستخدمين.
> **تحذير:** تغيير `ENCRYPTION_KEY` يجعل مفاتيح API المخزّنة سابقًا غير قابلة لفك التشفير. لا تغيّره دون خطة معتمدة لإعادة التشفير أو لإعادة إدخال المفاتيح من المستخدمين.

### بقية المتغيرات

| الفئة | أسماء المتغيرات |
|---|---|
| المنصة وقاعدة البيانات | `DATABASE_URL`, `JWT_SECRET`, `ENCRYPTION_KEY`, `VITE_APP_ID`, `OAUTH_SERVER_URL`, `VITE_OAUTH_PORTAL_URL` |
| بيانات السوق | `COINGECKO_API_KEY`, `TWELVE_DATA_API_KEY` |
| بيانات On-Chain | `ALCHEMY_API_KEY`, `ALCHEMY_WEBHOOK_SIGNING_KEY` |
| تكاملات Manus المضمنة | `BUILT_IN_FORGE_API_KEY`, `BUILT_IN_FORGE_API_URL`, `VITE_FRONTEND_FORGE_API_KEY`, `VITE_FRONTEND_FORGE_API_URL` |

> لا تضع أي سر في الواجهة أو المستودع. استخدم مدير أسرار في بيئة النشر، وطبّق ترحيلات `drizzle/` على قاعدة TiDB/MySQL قبل تشغيل الخادم في الإنتاج.

## Gold XAU/USD

تكامل Gold يستخدم `TWELVE_DATA_API_KEY` على الخادم فقط. قبل العرض التجاري العام، تحقّق من ترخيص Twelve Data لعرض وإعادة توزيع البيانات.
